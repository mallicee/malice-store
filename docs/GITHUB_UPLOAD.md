# Uploading MALICE to GitHub (web interface)

1. Create a repository named `malice-store` on GitHub. Public is suitable for a portfolio only after checking that no secrets or private data are present.
2. Extract the `MALICE_GITHUB_READY.zip` archive locally.
3. Open the new repository and choose **Add file → Upload files**.
4. Upload the project contents: `README.md`, `.gitignore`, `.env.example`, `requirements.txt`, `bot/`, `website/`, and `docs/`.
5. Do **not** upload `.env` or any database file such as `malice_v3.db`.
6. Review the upload list before choosing **Commit changes**.

GitHub's web uploader may require dragging the files inside the extracted folder rather than the ZIP file itself.
